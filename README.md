# FootballIQ ⚽🧠

FootballIQ is an AI-powered football scouting and match analysis platform.

## Features

- Automated FPF data collection
- Match parser
- Validation pipeline
- FastAPI backend
- PostgreSQL (coming soon)
- Power BI dashboards (coming soon)
- Machine Learning models (coming soon)

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Power BI
- Next.js
- Spring Boot
